# MediaFrame

A neutral 4:3 frame for the camera preview or the generated career image, with a label above and actions below. It should feel functional, not futuristic.

Provide `label`, a `placeholder` for the empty state, the `<img>`, `<video>` or `<canvas>` as children once there is media, and `actions` (Capture Photo, Retake Photo, Generate Visualization). Give generated images meaningful alt text.

Place Your Photo and Career Visualization side by side on desktop, stacked on mobile, with the privacy `Notice` above them.
