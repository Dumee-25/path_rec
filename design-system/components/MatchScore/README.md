# MatchScore

A score printed as "92 / 100" in Manrope over one solid bar. The primary match uses `brand-green` at 56px (44px mobile); other matches use `brand-blue` at the small size.

Provide `score`, optional `max` (100), `tone` and `label`. Never use gradient bars or medal colours, and always print the number: the bar is never the only signal.
