# Button

Primary is NSBM green with an `on-green` label; use it once per view for the main action. Secondary is neutral (`surface`, `border-strong`, `text-primary`) for Back, Retake Photo and other supporting actions.

Both are 44px tall with `radius-button` (9px) and a 1px lift on hover. Never fade with opacity and do not turn secondary actions blue. Disabled Continue (before an answer is chosen) greys out to `surface-subtle`.

Labels are short Title Case verbs from the copy list: Start Recommendation, Continue, Back, Capture Photo, Retake Photo, Generate Visualization. `fullWidth` suits the sticky mobile Continue bar.
